## 几条硬结论

- **decode 是带宽问题，不是算力问题**：DeepSeek-R1 8 卡节点 MFU 约 0.6%，单用户约 0.03%；EP144 才回到 20–25%。
- **AFD 不是普适加速**：在 GB200 NVL72 上相对调优 wide EP 只 1.16–1.17×，胜负由 batch gain + overlap gain − disaggregation cost 决定。
- **均衡指标换代**：token 数 → 激活专家数 → 两段代价模型 → 把均衡降为约束、直接优化瓶颈通信。
- **故障收缩**：wide EP 单 rank 故障，全重启 348s，原地修复可压到 11s + 8s，52s 恢复 95% 吞吐。
