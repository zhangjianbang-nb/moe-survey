TAKEAWAY一句话结论

MoE 的历史不是「模型一代比一代大」的线性叙事，而是一部瓶颈迁移史。

MoE 把参数容量与每 token 计算量解耦：省算力，但不省显存。

容量 → 路由 → 通信 → 显存 → 带宽 → 精度 → 调度 → 存储

DeepSeek-V3 训练 2.788M H800 小时；V4.1 推理约 890 B/token；EP/all-to-all 约 939 MB/layer，是推理的第一瓶颈。

推理优化主线：grouped GEMM、EPLB、PD 分离、FP8/FP4。
